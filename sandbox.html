Python sandbox

Real Python 3 running in your browser through Pyodide. Nothing is installed and nothing leaves your machine. Try your own code, or paste a snippet from a lesson. Ctrl+Enter (or ⌘+Enter) runs it.


    

    
Available in the browser: the standard library, NumPy, pandas, and scikit-learn. Each one loads
      automatically the first time your code imports it, so the first run can take a while. Plots and PyTorch need
      Google Colab or a local install (see Units 18, 20, and 21).
